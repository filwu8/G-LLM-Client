G-LLM Client هو تطبيق ذكاء اصطناعي لسطح المكتب لأنظمة Windows وmacOS وLinux، طورته GPROPHET LIMITED. يركز التطبيق على المساعدين ويجمع إعداد النماذج ومراجع المعرفة والأسئلة عبر لقطات الشاشة وفهم الملفات والمحادثات ومهام مساحة العمل.

## الميزات الرئيسية

- مساعدون متخصصون مع إمكانية إعداد النماذج وSkills والأدوات والمساعدين المتعاونين.
- قراءة الملفات وتعديلها وإنشاؤها داخل المجلدات التي يصرح بها المستخدم، مع عرض خطوات التنفيذ.
- وضع الأهداف المستقلة للتخطيط واستخدام الأدوات والعمل المستمر والتحقق من النتائج.
- دعم واجهات OpenAI-compatible السحابية والمحلية وواجهات الشبكة الداخلية.
- بحث الويب ونماذج إنشاء الصور وقاعدة المعرفة والمحادثة السريعة وإحصاءات الاستخدام المحلية.
- تُحفظ المحادثات والإعدادات وبيانات العمل محليًا بشكل افتراضي.
