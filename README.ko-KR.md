G-LLM Client는 GPROPHET LIMITED가 개발한 Windows, macOS, Linux용 데스크톱 AI 클라이언트입니다. 어시스턴트를 중심으로 모델 설정, 지식 참조, 스크린샷 질문, 파일 이해, 다중 턴 대화 및 워크스페이스 작업을 하나의 앱에서 제공합니다.

## 주요 기능

- 역할별 어시스턴트와 모델, Skill, 도구 및 협업 어시스턴트 구성.
- 사용자가 허용한 폴더에서 파일 읽기, 수정, 생성 및 실행 과정 표시.
- 자율 목표 모드에서 단계 계획, 도구 호출, 지속 실행 및 결과 검증.
- 클라우드, 로컬 및 LAN의 OpenAI-compatible API 지원.
- 웹 검색, 이미지 생성 모델, 지식 베이스, 빠른 대화 및 로컬 사용 통계.
- 대화, 설정 및 작업 데이터는 기본적으로 로컬에 저장됩니다.
