G-LLM Client 是 GPROPHET LIMITED 自主研發的跨平台桌面 AI 用戶端，支援 Windows、macOS 與 Linux。它以助手為核心，整合模型設定、知識引用、螢幕截圖提問、檔案理解、多輪對話和工作區任務。

## 核心功能

- 建立不同職責的助手，並設定模型、Skill、工具和可協作助手。
- 在使用者授權的資料夾中讀取、修改與產生檔案，並顯示執行過程。
- 自主目標模式可規劃步驟、呼叫工具、持續執行並驗證交付成果。
- 支援 OpenAI-compatible 雲端、本機與區域網路 API。
- 支援聯網搜尋、圖片生成模型、知識庫、快速對話與本機使用統計。
- 對話、設定與工作資料預設保存在本機。
