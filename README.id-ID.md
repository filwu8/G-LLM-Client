G-LLM Client adalah klien AI desktop untuk Windows, macOS, dan Linux yang dikembangkan oleh GPROPHET LIMITED. Aplikasi yang berpusat pada asisten ini menggabungkan konfigurasi model, referensi pengetahuan, pertanyaan melalui tangkapan layar, pemahaman berkas, percakapan, dan tugas ruang kerja.

## Fitur utama

- Asisten berbasis peran dengan model, Skills, alat, dan asisten kolaborasi yang dapat dikonfigurasi.
- Membaca, mengubah, dan membuat berkas di folder yang diizinkan pengguna, dengan proses kerja yang terlihat.
- Mode tujuan otonom untuk merencanakan langkah, menggunakan alat, bekerja berkelanjutan, dan memverifikasi hasil.
- Mendukung API OpenAI-compatible di cloud, komputer lokal, dan jaringan LAN.
- Pencarian web, model pembuatan gambar, basis pengetahuan, percakapan cepat, dan statistik penggunaan lokal.
- Percakapan, pengaturan, dan data kerja disimpan secara lokal secara bawaan.
