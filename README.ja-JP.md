G-LLM Client は、GPROPHET LIMITED が開発する Windows、macOS、Linux 対応のデスクトップ AI クライアントです。アシスタントを中心に、モデル設定、ナレッジ参照、スクリーンショット、ファイル理解、複数ターンの会話、ワークスペース作業を一つにまとめます。

## 主な機能

- 役割別アシスタントと、モデル、Skill、ツール、連携アシスタントの設定。
- 許可したフォルダー内でのファイル読み取り、編集、生成と作業状況の表示。
- 自律目標モードによる計画、ツール実行、継続作業、成果物の検証。
- クラウド、ローカル、LAN 上の OpenAI-compatible API に対応。
- Web 検索、画像生成モデル、ナレッジベース、クイックチャット、ローカル利用統計。
- 会話、設定、作業データは既定でローカルに保存。

## インストール

[ダウンロードページ](https://llm.gprophet.com/download)または [GitHub Releases](https://github.com/filwu8/G-LLM-Client/releases) から、お使いの OS 向けビルドを入手してください。
