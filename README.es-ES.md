G-LLM Client es un cliente de IA de escritorio para Windows, macOS y Linux desarrollado por GPROPHET LIMITED. Su diseño se centra en asistentes y reúne configuración de modelos, referencias de conocimiento, capturas de pantalla, comprensión de archivos, conversaciones y tareas de espacio de trabajo.

## Funciones principales

- Asistentes por función con modelos, Skills, herramientas y asistentes colaboradores configurables.
- Lectura, edición y creación de archivos dentro de carpetas autorizadas, con actividad visible.
- Modo de objetivos autónomos para planificar, usar herramientas, trabajar de forma continua y verificar resultados.
- Compatibilidad con API OpenAI-compatible en la nube, el equipo local y la red LAN.
- Búsqueda web, modelos de generación de imágenes, base de conocimiento, chat rápido y estadísticas locales.
- Conversaciones, ajustes y datos de trabajo almacenados localmente de forma predeterminada.

## Instalación

Obtén la versión para tu sistema en la [página de descargas](https://llm.gprophet.com/download) o en [GitHub Releases](https://github.com/filwu8/G-LLM-Client/releases).
