G-LLM Client — настольный ИИ-клиент для Windows, macOS и Linux, разработанный GPROPHET LIMITED. Приложение ориентировано на ассистентов и объединяет настройку моделей, базу знаний, вопросы по снимкам экрана, работу с файлами, диалоги и задачи в рабочей папке.

## Основные возможности

- Ролевые ассистенты с настраиваемыми моделями, Skills, инструментами и ассистентами для совместной работы.
- Чтение, изменение и создание файлов в разрешённых папках с отображением хода выполнения.
- Автономный режим целей для планирования, вызова инструментов, непрерывной работы и проверки результатов.
- Поддержка OpenAI-compatible API в облаке, на локальном компьютере и в локальной сети.
- Веб-поиск, модели генерации изображений, база знаний, быстрый чат и локальная статистика.
- Диалоги, настройки и рабочие данные по умолчанию хранятся локально.
