# G-LLM Client V2.0.9

V2.0.9 集中修复近期真实使用测试发现的会话、工作区、截图、文档生成和联网检索问题，同时在不降低任务效果的前提下减少长任务 Token 消耗。

## 会话与工作区稳定性

- 修复授权工作区在切换模型后消失的问题；模型和推理等级变化不再覆盖当前目录授权。
- 阻止连续点击“新建会话”生成多个未使用的空白助手会话，并复用当前空白草稿。
- 修复部分请求发送后没有进入正确运行状态或没有反馈的问题，完善前台与后台会话的请求生命周期管理。
- 点击停止后会同步结束仍处于规划或搜索中的状态，避免“正在理解搜索意图”继续旋转。
- 编辑旧消息时，输入区域会约束在消息卡片内并适应窄窗口，不再溢出背景框。
- 增强本地诊断日志并对凭据做脱敏，方便定位模型超时、重试、网络和工作区执行故障。

## macOS 截图与图片体验

- macOS 使用系统原生交互式区域截图，不再依赖剪贴板；能够区分用户取消与屏幕录制权限不足。
- 截图和图片附件在聊天记录中以更大尺寸显示，点击缩略图可打开大图预览。
- 主聊天和快速对话使用一致的图片预览体验，金色主题下也保持清晰边界和对比度。

## Word 文档与最终交付物

- 将 Markdown 表格转换为真正可编辑的 Word 表格，不再把竖线分隔文本直接写入 DOCX。
- 改进表格列宽、转义和固定布局，避免孤立竖线被误判为表格。
- 生成后校验 DOCX 容器和必要结构，阻止文本伪装成 `.docx` 或损坏文档成为最终交付物。
- 用户明确要求 Word 时保留 DOCX，明确要求 PDF 时才交付 PDF；格式转换仅用于内部验证时不会替换用户要求的文件。
- 默认只保留一个最终文档；模型后续补充 Logo 或样式时会更新原交付物，除非用户明确要求多个版本。

## 联网搜索与 Token 优化

- 新增 Auto / On / Off 三种联网模式：默认 Off，用户选择会作为全局偏好保存，并在新会话、模型切换、主窗口、快速对话和重启后保持一致。
- Auto 由客户端使用确定性规则判断是否需要联网，不额外调用模型分类器消耗 Token；On 对实质性问题强制联网，Off 只使用模型知识、本地文件和当前对话。
- 搜索规划增加确定性降级路径，降低免费模型规划超时导致整轮失败的概率，并在搜索源不足时补充可恢复结果。
- 长对话会保留最新用户指令，压缩较早的大段消息；工作区读取支持分段，大型旧工具载荷会变成可核验摘要，同时保留最新读取结果原文。
- 主聊天和快速对话显示本轮上下文节省比例，便于用户看到实际 Token 优化效果。

## 界面优化

- 优化金色模式中的消息卡片、编辑器、输入区、活动时间线、边框和滚动条，使金色作为强调色而不是大面积高亮背景。
- 修复超长模型名称与输入文字、发送按钮重叠的问题，模型选择器在空间不足时自动收缩和换行。
- 联网模式菜单三项标题与说明统一左对齐，并适配普通、金色和窄窗口布局。

## 更新方式

- Windows V2.0.8 用户可由客户端自动下载并安装 V2.0.9。
- Apple Silicon Mac（M1/M2/M3/M4 等）：下载 `G-LLM-Client-Setup-2.0.9-arm64.dmg`。
- Intel Mac：下载 `G-LLM-Client-Setup-2.0.9-x64.dmg`。
- Linux：可选择 `x86_64.AppImage` 或 `amd64.deb`。
- 本版本继续采用无证书发布；Windows/macOS 可能显示未知发布者或安全警告，macOS 与 Linux 仍需手动更新。

## English Summary

V2.0.9 is a stability and usability release based on extended local user testing. Workspace authorization now survives model changes; repeated blank conversations are prevented; stopped search activity exits its running state; message editing stays inside its card; and request lifecycle handling plus redacted diagnostic logs make silent failures easier to prevent and diagnose.

macOS now uses native interactive region capture with clearer cancellation and permission errors. Sent screenshots and image attachments render larger and open in a full-size preview in both the main chat and Quick Chat.

Word generation converts Markdown tables into real editable DOCX tables and validates the generated document container. The client preserves the user's requested output format and keeps one final document unless multiple variants are explicitly requested.

Web search now has global Auto, On, and Off modes. It defaults to Off and remembers the user's selection across conversations, models, windows, and restarts. Auto uses deterministic client-side rules without a model-classifier token cost. Search planning has deterministic timeout fallbacks, while long conversations and workspace transcripts compact older context without dropping the latest instruction or the newest verifiable tool result. The UI reports the resulting context savings.

This release also refines the gold theme, model picker, message editor, screenshot preview, and web-search menu across regular and narrow layouts.

Windows V2.0.8 clients can install this release through the in-app updater. macOS and Linux remain manual downloads under the current certificate-free distribution model.
