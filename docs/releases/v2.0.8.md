# G-LLM Client V2.0.8

V2.0.8 为主聊天和快速对话增加“编辑并重新发送”功能。

## 编辑并重新发送

- 用户已经发送的消息下方新增铅笔按钮，可在原消息位置直接修改内容。
- 支持点击“重新发送”，也支持 `Command/Ctrl + Enter` 快捷发送；按 `Escape` 可取消编辑。
- 重新发送后，会保留该消息之前的会话上下文，并替换该消息之后的旧回复分支。
- 如果被替换的旧分支已写入项目长期记忆，客户端会丢弃受影响的旧记忆，避免旧答案污染新分支。
- 原消息附带的图片、文件、引用和知识库上下文会继续保留。
- 绑定授权文件夹的会话会继续使用工作区代理和当前授权，不会退回普通聊天。
- 重新请求沿用当前会话所选供应商、模型、推理等级与联网搜索设置。
- 主聊天窗口和快速对话窗口提供一致的编辑体验。

## 更新方式

- Windows V2.0.7 用户可由客户端自动下载并安装 V2.0.8。
- Apple Silicon Mac（M1/M2/M3/M4 等）：下载 `G-LLM-Client-Setup-2.0.8-arm64.dmg`。
- Intel Mac：下载 `G-LLM-Client-Setup-2.0.8-x64.dmg`。
- Linux：可选择 `x86_64.AppImage` 或 `amd64.deb`。
- 本版本继续采用无证书发布；Windows/macOS 可能显示未知发布者或安全警告，macOS 与 Linux 仍需手动更新。

## English Summary

V2.0.8 adds Edit and Resend to sent user messages in both the main chat and Quick Chat. Editing preserves earlier conversation context as well as the original attachments, quotes, and knowledge references, while replacing the replies after the edited message. Workspace authorization and the conversation's current provider, model, reasoning effort, and web-search setting remain in effect.

Use the pencil action below a user message, then click Resend or press `Command/Ctrl + Enter`; press `Escape` to cancel.

Windows V2.0.7 clients can install this release through the in-app updater. macOS and Linux remain manual downloads under the current certificate-free distribution model.
