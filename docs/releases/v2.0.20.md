# G-LLM Client V2.0.20

V2.0.20 将工作区助手扩展为可执行本地程序的 Agent，并完善授权、加密变量、环境检查和上下文预算。

## 本地执行与三档授权

- 在已授权工作区主动启用 Python/Shell，默认使用 macOS Seatbelt、Linux Bubblewrap + seccomp 或 Windows AppContainer + Job Object。
- 请求批准逐次确认写入、脚本与扩展 HTTP 工具；帮我批准自动执行已配置沙箱内的操作，主机执行与扩展 HTTP 工具仍询问；完全授权自动运行已启用工具。
- 授权档位与沙箱、网络和变量权限独立；未绑定文件夹的会话不会继承草稿授权，解绑会取消执行及待处理审批。
- 沙箱默认禁网，开启后允许互联网及局域网访问；不可用或失败时明确报错，不自动退回主机执行。

## 可复用配置与可见的检查结果

- 自动读取根目录 `AGENTS.md`，由模型声明业务所需的变量名和用途，用户在 Agent 设置中填写值并选择允许注入的变量。
- 值使用系统凭据加密能力保存在本机，按工作区隔离；不提供明文回读或明文存储降级。兼容读取 `.env`，加密保存的已授权同名值优先。
- 自动检查 Python、Shell、测试文件回写、目录隔离以及已启用的 DNS/TCP 联网；检查不使用业务密钥或验证业务 API 登录。
- 修复 macOS Shell 误用系统/Xcode Python 启动器及沙箱联网缺少 DNS 访问的问题。变量名称与输入框对齐，描述改为悬停显示。

## 更少的无关上下文与重复执行

- 新增文件范围批量读取、定点搜索与稳定续读；已知模型按参考词表限制工具输出，未知模型使用明确的字节预算。
- 长工具输出先脱敏再保留于当前运行的有界内存存储，支持取回中间内容，避免为获取日志重复执行有副作用的命令。
- 后台任务提供增量日志、末尾跳读、状态查询和取消，默认 120 秒、可指定最多 600 秒，受整轮时限约束且不跨运行持久化。
- 批量文字替换先预演再按授权档位提交；检查匹配次数及文件版本，冲突时避免覆盖新修改。逐文件原子替换，不承诺跨文件事务。
- 改进连续生图请求的上下文衔接与图片保存文件名处理。

## 更新与兼容性

- Windows 用户可通过客户端自动更新；macOS/Linux 从本次发布下载安装包。
- Apple Silicon：`G-LLM-Client-Setup-2.0.20-arm64.dmg`；Intel Mac：`G-LLM-Client-Setup-2.0.20-x64.dmg`；Linux 提供 AppImage 和 deb。
- Python/Shell 需安装 Python 3 并主动启用。Linux 需 `/usr/bin/bwrap`、可用的用户命名空间及系统 Python；Windows Python 安装需可被 AppContainer 读取。macOS Seatbelt 为已弃用的系统接口，需随系统升级验证兼容性。
- 自动授权不限制已允许联网命令的业务影响；加密保护静态存储，已注入的值可被脚本使用。跨平台边界详见 [Agent 文档](https://github.com/filwu8/G-LLM-Client/blob/v2.0.20/docs/agent-execution.md)。
- 延续现有无证书发布方式，Windows/macOS 可能显示系统安全提示。许可证继续为 BUSL-1.1，转换日期以本版本 LICENSE 为准。

## English Summary

V2.0.20 adds opt-in local Python/Shell execution with OS sandboxes, a consistent three-mode approval policy, workspace-scoped encrypted variables, and real execution diagnostics. Models declare configuration names; users control values and injection permissions locally. Unbound conversations do not inherit draft folder grants, and unbinding cancels execution and pending approvals.

Ask for approval prompts for writes, scripts and HTTP extensions. Approve for me automatically permits configured sandbox operations while host commands and HTTP extensions still ask. Full authorization runs enabled tools without repeated prompts. Approval never expands sandbox, network or variable permissions. Sandbox networking defaults to off, and failed isolation never falls back to host execution.

FastCtx-inspired range reads, focused searches, shared reference-token/byte budgets and recoverable redacted output reduce unnecessary context. Background jobs provide incremental logs and cancellation within the current run; batch replacements require previews, exact match counts and file-version checks. Provider usage, not reference tokenization, determines billed consumption. Image follow-up context and suggested save names are also improved.

Diagnostics exercise Python, Shell, temporary writeback, isolation and enabled DNS/TCP connectivity without business credentials or API calls. This release corrects macOS Shell Python selection and DNS permissions. Variable inputs are aligned, with descriptions shown on hover.

Python/Shell remains opt-in and requires Python 3. Linux additionally requires Bubblewrap, supported user namespaces and system Python; Windows requires an AppContainer-readable Python installation. macOS uses the deprecated Seatbelt interface. Windows supports in-app updates; macOS/Linux installers remain manual. Existing unsigned distribution and BUSL-1.1 licensing continue.
