# G-LLM Client V2.0.15

V2.0.15 新增完全基于本机数据的使用统计，并统一优化 Windows 与 macOS 的设置界面顶部布局。

## 本机数据统计

- 在个性设置之后新增独立的“数据统计”标签页，与数据存储、导入和导出功能分开管理。
- 展示累计 Token 数、单日峰值 Token 数、最长聊天时长、当前连续天数与最长连续天数。
- 新增最近 12 周 Token 活跃热力图，以及常用模型、常用助手、常用工具和工具调用次数排行。
- 所有统计均由当前设备及用户主动导入的本地数据计算，不上传聊天内容，也不声称覆盖账号生命周期。
- 清除本机数据后统计会同步重新计算；导入历史数据后，相关使用记录会自动纳入统计。

## 跨平台界面优化

- Windows 设置抽屉背景延伸至原生标题栏，消除顶部空白区域与窗口按钮之间的割裂感。
- 设置标签改为统一的分段导航，当前标签更清晰，整体视觉层级更轻。
- macOS 设置抽屉针对内嵌标题栏增加独立安全间距，兼顾旧款 MacBook 和不同显示缩放比例。
- 数据存储页移除重复的本机概览，让存储管理与使用洞察职责更加明确。

## 更新方式

- Windows V2.0.14 用户可由客户端自动下载并安装 V2.0.15。
- Apple Silicon Mac（M1/M2/M3/M4 等）：下载 `G-LLM-Client-Setup-2.0.15-arm64.dmg`。
- Intel Mac：下载 `G-LLM-Client-Setup-2.0.15-x64.dmg`。
- Linux：可选择 `x86_64.AppImage` 或 `amd64.deb`。
- 本版本继续采用无证书发布；Windows/macOS 可能显示未知发布者或安全警告，macOS 与 Linux 仍需手动更新。

## English Summary

V2.0.15 adds a dedicated, privacy-preserving Data Insights tab calculated entirely from data stored on the current device or explicitly imported by the user. It reports total and peak daily tokens, longest chat duration, current and longest activity streaks, a 12-week activity heatmap, and rankings for frequently used models, assistants, and tools. No chat content is uploaded, and the figures are not presented as an account-wide lifetime total.

The release also removes the duplicated overview from Data Storage, unifies settings tabs into segmented navigation, extends the Windows drawer behind the native title bar, and adds macOS-safe spacing for the inset title bar. Windows V2.0.14 clients can update automatically; macOS and Linux remain manual downloads under the current certificate-free distribution model.
