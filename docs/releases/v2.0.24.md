# G-LLM Client V2.0.24 (unreleased)

## 安全修复

- 更新 Mermaid、DOMPurify、fast-uri 和 KaTeX，替换 Mammoth 的命令行解析依赖，修复此前 10 项生产依赖告警。
- 更新 tar、brace-expansion、esbuild、PostCSS、nanoid、source-map-js、Browserslist 和浏览器映射数据，修复开发与打包工具告警。
- 将 Electron 下载工具统一至 @electron/get 5.1.0，移除旧 got/cache 和 global-agent/sprintf-js 依赖链。
- 完整依赖审计覆盖生产、开发与可选依赖；CI 与发布工作流现在拒绝所有严重等级的告警。
- 增加数学渲染、Word 转换和下载校验、缓存复用、篡改拒绝回归检查。

## 构建兼容性

构建要求 Node.js 22.12.0 或更新版本，CI 使用 Node.js 24。下载代理配置使用 HTTP_PROXY、HTTPS_PROXY、NO_PROXY；GLOBAL_AGENT_* 不再适用。Windows 安装包仍为 x64 NSIS EXE，当前尚未配置商业代码签名或 MSIX。

本版尚未发布；最新稳定版仍为 V2.0.23。商店提交前仍需完成公司开发者账号验证、确定签名或 MSIX 分发方案，并进行安装和升级验收。

## English

This unreleased security update addresses the previously reported production and build-tool dependency advisories, removes legacy download dependency chains, and makes full dependency auditing a CI and release requirement. Regression coverage includes safe math rendering, Word conversion, artifact checksum validation, cache reuse, and tamper rejection.

Build tools require Node.js 22.12.0 or newer. Download proxy settings use HTTP_PROXY, HTTPS_PROXY, and NO_PROXY instead of GLOBAL_AGENT_*. Windows packages remain x64 NSIS EXE installers; commercial signing and MSIX are not yet configured. Microsoft Store submission and installation/upgrade acceptance testing remain pending.
