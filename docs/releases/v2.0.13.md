# G-LLM Client V2.0.13

V2.0.13 提升自部署模型兼容性、工作区 Agent 的长推理恢复能力、搜索等待反馈和 Windows 自动更新可靠性。

## 本机与局域网模型

- 本机、私有网段和局域网主机上的 OpenAI-compatible 服务可以不填写 API Key 直接连接。
- 需要请求头的自部署服务仍可填写真实密钥或 `123456` 等占位值，客户端会正常发送 Bearer Token。
- 客户端会把多条系统说明合并为唯一的首条 `system` 消息，兼容要求严格消息顺序的 Qwen 等服务。
- 未开启“最大输出词元”时，工作区请求不再固定限制为 4096 tokens，而是由上游推理服务采用其模型配置。

## 工作区 Agent

- 补全“开发、做成、构建、搭建、打包、部署”等实际工作区操作意图，避免代码开发任务被误判为普通问答。
- 当模型以 `finish_reason=length` 结束、只产生推理且没有正文或工具调用时，客户端会记录恢复过程并自动要求模型停止展开思考、立即调用工具。
- Qwen 系列在这一恢复请求中使用 `/no_think` 提示，将复杂任务拆为可执行的小步骤。
- 自定义 OpenAI-compatible 服务的 system 消息兼容处理同时覆盖普通聊天、联网规划、研究回答和工作区任务。

## 搜索等待反馈

- 搜索结果已经显示但模型仍在组织回答时，结果卡片底部持续显示“正在分析搜索结果并组织回答”。
- 状态包含流动光影、跳动点、当前模型和实时等待时长，并在正文或推理内容开始输出后自动消失。
- 主窗口与快速对话使用同一套反馈逻辑；普通模型等待提示也使用一致的光影效果。

## 自动更新与安装包

- Windows 自动更新改为下载完整安装包，避免差分缓存或 blockmap 不一致造成下载达到 100% 后无法安装。
- 临时断线、超时、限流及可恢复的服务器错误会自动重试；安装包真正下载完成前，进度最高显示为 99.9%。
- 打包阶段把 JSZip 内联到 Electron 主进程，并增加产物校验，修复 ASAR 中 ESM 解析扩展名入口失败导致工作区任务无法启动的问题。

## 更新方式

- Windows V2.0.12 用户可由客户端自动下载并安装 V2.0.13。
- Apple Silicon Mac（M1/M2/M3/M4 等）：下载 `G-LLM-Client-Setup-2.0.13-arm64.dmg`。
- Intel Mac：下载 `G-LLM-Client-Setup-2.0.13-x64.dmg`。
- Linux：可选择 `x86_64.AppImage` 或 `amd64.deb`。
- 本版本继续采用无证书发布；Windows/macOS 可能显示未知发布者或安全警告，macOS 与 Linux 仍需手动更新。

## English Summary

V2.0.13 improves compatibility with self-hosted OpenAI-compatible models, workspace-agent recovery, search wait feedback, and Windows automatic updates.

Local and private-network endpoints can connect without an API key or send a real or placeholder Bearer token. Multiple system instructions are merged into one leading system message for strict compatible servers. When the maximum-output setting is disabled, workspace requests no longer force a 4096-token limit and instead let the upstream service apply the model's configured budget.

The workspace agent now recognizes development, build, packaging, and deployment intent. If a model exhausts its output budget on reasoning without returning text or a tool call, the client records the recovery and retries with a direct-execution instruction; Qwen models also receive `/no_think` for that recovery turn.

After web research completes, the main window and Quick Chat show a shimmering status, model name, and live elapsed time while the answer is being composed. Windows updates now use full-installer downloads, retry transient failures, and avoid displaying 100% before the installer is ready. JSZip is bundled into the main process and verified during builds to prevent packaged ASAR resolution failures.

Windows V2.0.12 clients can install this release through the in-app updater. macOS and Linux remain manual downloads under the current certificate-free distribution model.
