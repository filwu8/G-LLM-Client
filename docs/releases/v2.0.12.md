# G-LLM Client V2.0.12

V2.0.12 优化 Windows 与 macOS 的系统图标显示，并让快速对话完整展示联网搜索过程。

## Windows 托盘图标

- 修复最小化到系统托盘后图标空白的问题，并改用与 macOS 菜单栏一致的完整单色 Logo。
- 图标根据 Windows 系统任务栏的实际深浅色自动选择黑色或白色版本，不再跟随客户端内部主题而产生低对比度显示。
- 新增 16、20、24、32、40、48 和 64 像素原生 ICO 帧，改善不同 DPI 缩放下的边缘毛刺。
- 略微增大 Logo 的有效占用面积，使其与相邻托盘图标的视觉尺寸更协调。

## macOS Dock 图标

- 为 macOS 使用独立的 1024 像素 Dock 图标资源，并加入符合系统图标观感的安全留白。
- 修正旧款 MacBook 上 Dock 图标明显大于其他应用的问题，同时保持新款设备上的尺寸协调。

## 快速对话联网搜索

- 小窗口聊天现在与主窗口一样展示搜索规划、正在执行与已完成的查询、实时进度、结果审查、来源以及失败状态。
- 主窗口与快速对话共用同一搜索过程组件，避免后续功能和样式出现差异。
- 联网搜索尚未产生正文时不再额外显示重复的“思考中”占位。

## 更新方式

- Windows V2.0.11 用户可由客户端自动下载并安装 V2.0.12。
- Apple Silicon Mac（M1/M2/M3/M4 等）：下载 `G-LLM-Client-Setup-2.0.12-arm64.dmg`。
- Intel Mac：下载 `G-LLM-Client-Setup-2.0.12-x64.dmg`。
- Linux：可选择 `x86_64.AppImage` 或 `amd64.deb`。
- 本版本继续采用无证书发布；Windows/macOS 可能显示未知发布者或安全警告，macOS 与 Linux 仍需手动更新。

## English Summary

V2.0.12 improves system icon rendering on Windows and macOS and brings full web-search progress to Quick Chat.

The Windows tray now uses a complete monochrome logo that follows the actual taskbar appearance, choosing black on light taskbars and white on dark taskbars. Native 16, 20, 24, 32, 40, 48, and 64-pixel ICO frames reduce jagged edges at different DPI scales, and the artwork is slightly larger for better visual balance.

macOS now packages a dedicated 1024-pixel Dock icon with a safe-area inset. This corrects the oversized appearance seen on older MacBooks while preserving a balanced size on newer hardware.

Quick Chat now displays research planning, active and completed queries, live progress, result review, sources, and failures through the same shared component as the main window. A duplicate thinking placeholder is no longer shown before answer text arrives.

Windows V2.0.11 clients can install this release through the in-app updater. macOS and Linux remain manual downloads under the current certificate-free distribution model.
