# G-LLM Client 2.0.31 Windows update

Microsoft certified and publicly released the Windows x64 MSIX `2.0.31.0` on 2026-11-13. The live Store submission offers it for Windows 10/11 desktop devices with build 19041 or later. Microsoft's public update service returned the exact `2.0.31.0` x64 package identity for both China and the United States. The local private flight installation was still on `2.0.30.0` during verification.

**简体中文**

- 工作区 Agent 根据用户目标验证结果，自动整理长任务的上下文，并在短暂服务故障后重试。重载会话界面可接回正在运行的任务，重启应用后可从已保存的进度继续。
- 工作区工具栏在宽度足够时单行排列，窄窗口下自动换行。
- 此版本包含个人账号登录后自动配置与额度查询，以及对选定 Windows 应用窗口和现有浏览器窗口的逐次授权操作。

**English**

- The workspace agent verifies results against the user's goal, compacts context for long tasks, and retries temporary service failures. Reloading a conversation reattaches to active work, and tasks can resume from saved progress after an app restart.
- The workspace toolbar fits on a single row when space allows and wraps in narrower windows.
- This version includes automatic setup and allowance lookup after personal sign-in, plus per-action approval for operating selected Windows app windows and existing browser windows.

The Windows SDK built `G-LLM-Client-2.0.31-x64.msix` (321,509,537 bytes). SHA-256 `722438622549f22c9f149eccbd7149e86b038b9f0c675e8f7e5de7ac75245c8c`. The package keeps the existing Store identity and `gllm` protocol. Its ASAR matches the tested build.

The production build, 248 regression tests (11 skipped), 13 account tests, and workspace integration passed. The packaged Electron app verified single delivery after a renderer reload and toolbar layout at widths of 1000 and 260 pixels. The six packaged account scenarios passed with screenshot capture disabled after Chromium returned `UnknownVizError` on the test host.
