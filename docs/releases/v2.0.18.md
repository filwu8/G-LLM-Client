# G-LLM Client V2.0.18

V2.0.18 让对话模型的生图工具能力真正可用，同时重新设计模型与推理强度的选择交互，修复快速对话在首条消息前丢失模型选择的问题。

## 对话模型也能调用生图工具

- 新增对 Responses API 托管 `image_generation` 工具的调用，并与独立 Image API 路由分开。
- `gpt-6-astra`、GPT 5.4/5.5 与 GPT 5.6 Sol/Terra/Luna 等已知对话模型会标记为“生图工具”；上游明确返回的能力元数据也会被识别。
- 普通对话和工作区助手可识别用户明确的生图需求，并自动选择可用的图片模型或 Responses 生图工具。
- 生成结果支持 URL、Base64 以及 Responses 工具输出结构，并保存为客户端可继续展示的本地图片资源。

## 更清晰的模型选择

- 模型选择弹窗改为两层：第一层选择模型，第二层仅在模型支持时选择默认、低、中或高推理强度。
- 当前模型采用明确的左侧标记与勾选状态，鼠标悬停只显示轻量轮廓，不再与已选状态混淆。
- 右下角始终以独立标签显示当前推理强度；长模型名会优先省略，避免强度和发送按钮被挤压。
- 模型正在输出时，选择器会显示旋转与呼吸动效，并明确表示当前不可切换模型。
- 列表标签和强度区域会在窄窗口自动换行，主窗口与 Quick Chat 使用同一套响应式规则。

## 会话稳定性与图片下载

- 在 Quick Chat 中于首条消息前选择的模型、推理强度和未发送草稿会立即形成可持久会话，关闭后重新打开不再回退到默认模型。
- 对话消息、附件及全屏预览中的图片均可通过右键“图片另存为”下载。
- 保存流程仅允许受支持的本地图片资源和图片 Data URL，限制文件大小并清理建议文件名。

## 质量与兼容性

- 新增生图路由、模型能力、推理强度、模型选择持久化与生图请求识别的自动测试。
- 已实际验证 macOS 主窗口和 Quick Chat 的宽窄布局；Windows 与 Linux 将由同一响应式渲染代码构建。

## 更新方式

- Windows V2.0.17 用户可由客户端自动下载并安装 V2.0.18。
- Apple Silicon Mac（M1/M2/M3/M4 等）：下载 `G-LLM-Client-Setup-2.0.18-arm64.dmg`。
- Intel Mac：下载 `G-LLM-Client-Setup-2.0.18-x64.dmg`。
- Linux：可选择 `x86_64.AppImage` 或 `amd64.deb`。
- 本版本继续采用无证书发布；Windows/macOS 可能显示未知发布者或安全警告，macOS 与 Linux 仍需手动更新。

## English Summary

G-LLM Client V2.0.18 makes image-generation tools available from supported chat models while keeping direct image-model routing intact. Known models such as `gpt-6-astra`, GPT 5.4/5.5, and GPT 5.6 Sol/Terra/Luna can invoke the hosted `image_generation` tool through the Responses API. Explicit image requests in regular chat and workspace tasks automatically use an available direct image model or image-tool-capable chat model.

The model picker now separates model choice from reasoning-effort choice. Selected and hovered rows are visually distinct, unsupported efforts are disabled, and the current effort remains visible in the bottom-right selector. A running response replaces the switch affordance with an activity indicator. Narrow and wide layouts share responsive rules across the main window and Quick Chat.

Quick Chat now persists model and reasoning selections made before the first message, including unsent drafts, so reopening the window no longer falls back to the default model. Generated, attached, and previewed images can also be downloaded through a validated Save Image As flow.
