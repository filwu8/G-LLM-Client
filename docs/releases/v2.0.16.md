# G-LLM Client V2.0.16

V2.0.16 新增可持续执行、暂停、继续和取消的自主目标模式，并完善主窗口与小窗口中的工作区成果展示。

## 自主目标模式

- 用户可以设定最终目标与验收标准，授权一个工作文件夹，并配置执行权限、最大执行轮数和最长单次运行时间。
- 助手围绕目标自主理解需求、规划步骤、调用工作区工具、修改真实文件并验证交付结果，而不只是描述做法。
- 目标、运行次数、计划进度和最近验证结果随会话保存在本机；达到限制、客户端重启或手动暂停后均可继续。
- 暂停只中断当前执行并保留目标；取消会立即停止执行并移除目标，但不会删除聊天记录、已生成文件或工作区授权。
- 普通的停止生成按钮在目标运行期间也会同步暂停目标，避免状态显示不一致。

## 工作区与界面改进

- 主窗口与小窗口统一显示紧凑的当前目标卡片、绿色步骤标签和运行状态。
- 工作区 Agent 执行期间实时展示已生成或修改的文件，可直接点击打开文件，并可快捷打开授权文件夹。
- 小窗口的聊天输入按钮布局与大窗口保持一致，目标模式及其控制也完整同步。
- 模型管理新增搜索框，可按模型名称或模型 ID 快速筛选。

## 更新方式

- Windows V2.0.15 用户可由客户端自动下载并安装 V2.0.16。
- Apple Silicon Mac（M1/M2/M3/M4 等）：下载 `G-LLM-Client-Setup-2.0.16-arm64.dmg`。
- Intel Mac：下载 `G-LLM-Client-Setup-2.0.16-x64.dmg`。
- Linux：可选择 `x86_64.AppImage` 或 `amd64.deb`。
- 本版本继续采用无证书发布；Windows/macOS 可能显示未知发布者或安全警告，macOS 与 Linux 仍需手动更新。
