# 知言 · G-LLM Client 2.0.27

Microsoft Store update in preparation. The current public Store package is 2.0.26; GitHub's latest stable release remains 2.0.23.

## 本版变化

- 项目直接绑定文件夹；未选择目录时建立托管工作空间。拖入、上传和粘贴附件会保留原文件并导入工作空间，可通过会话文件面板查看和处理。已有会话保留自己的目录，更换项目目录应用于新会话。
- 数据目录迁移检查正在运行和清理中的任务，校验文件复制并修正工作空间、附件、产物和技能关联路径；原目录保留为恢复来源，外部项目文件夹保持原位。跳过 Chromium 单实例文件及符号链接，修复 macOS SingletonCookie 的 ENOENT。
- 普通助手和工作区助手均获知真实操作系统。电脑、浏览器分别授权，并逐次展示操作内容供批准；登录信息仍由用户手动输入。
- 支持通过对话预览并批准部分应用设置、创建或更新当前助手的技能。扩展与技能入口集中到设置；完整 MCP/插件执行尚未接通。
- AI 浏览器使用本应用图标；主窗口和快速对话提供“查看 AI 浏览器”，恢复当前会话已打开的窗口。每个会话一个页面，暂不支持多标签页、弹窗或下载。
- 修复工作空间栏重叠；开发与生产构建目录隔离，避免运行时任务模块被新构建清除。
- 更新 Electron 42.11.18、Vite 7.3.7 和 DOMPurify 3.4.17，修复发布检查发现的依赖安全告警。

## Validation

Release checks cover TypeScript, translation parity, production bundling, dependency auditing, unit tests, Electron browser operations, verified data migration, project attachment imports, and mandatory approval of application settings and skill changes. Integration tests use local fixtures and mock model responses without paid API calls. Windows is tested locally; macOS and Linux checks run in CI. Store certification and installation of the new Microsoft-signed package are separate from these checks.

## English

Projects bind to folders, attachments become workspace files while retaining originals, and conversations provide a file panel. Data relocation waits for running tasks, verifies copied files and updates managed references, including a fix for macOS Chromium singleton links. Assistants receive actual host information; computer/browser operations and supported settings/skill changes use explicit approval. Extensions move into Settings. The AI browser uses the app icon and can be brought forward from its conversation. It currently supports one page per conversation, without tabs, popups, or downloads. Development output is isolated from production builds to prevent missing runtime modules.

Application and Store identity, protocol, and user-data compatibility are retained. The existing free public Store distribution is retained. BUSL-1.1 terms and the existing 2030-08-01 Change Date are retained; LICENSE identifies version 2.0.27.
