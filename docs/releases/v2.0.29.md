# G-LLM Client 2.0.29 Windows Store candidate

Application version `2.0.29`. Windows x64 MSIX version `2.0.29.0`. Store submission is pending. This Windows candidate builds on the [2.0.28 implementation](v2.0.28.md).

The connection and allowance endpoints use the production G-LLM service (`v2.0.11-client-auth.20261105`, as reported by the service owner). The Windows probe observed HTTPS `200` for the connection page and `401` for an unauthenticated allowance request. Authenticated Windows acceptance is tracked separately from the service owner's Mac acceptance.

HTTP `429` from the exchange or allowance endpoint now pauses the affected requests in the main process. The client respects `Retry-After` and waits at least 30 seconds. The interface shows when the user can retry. A failed allowance query preserves authorization and does not block chat. Server registration rules manage new-user allowance.

## Microsoft Store release text

**简体中文**

首次使用知言时，可在浏览器注册或登录 G-LLM，返回客户端后自动配置个人账号并加载可用模型。可在客户端查看和刷新个人可用额度，也可以手动配置其他模型供应商。额度及其发放以服务端账号规则为准。

**English**

When you first open G-LLM Client, register or sign in to G-LLM in your browser. The client then connects your personal account and loads available models automatically. View or refresh your available account allowance in the app, or configure another model provider manually. Your allowance follows the service's account rules.
