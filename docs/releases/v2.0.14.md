# G-LLM Client V2.0.14

V2.0.14 把助手进一步升级为可持续演进的业务执行单元，并完善 Skill、助手协作、模型标记、运行反馈与生图模型编排。

## 助手工作流与 Skill

- 助手围绕用户目标建立执行计划，并在理解、检查、执行和验证过程中持续更新状态。
- 工作区工具由多个助手共享；助手只会调用用户明确授权的其他助手，并限制调用深度与循环关系。
- 扩展工具中心支持创建 Skill，也支持上传 Markdown Skill 文档。
- Skill 支持配置来源、版本记录、评测案例、反馈迭代与回滚，让一次修正可复用于后续任务。
- 删除助手后，其他助手中的授权引用会自动清理，避免无效配置造成异常。

## 界面与运行反馈

- 优化扩展工具、Skill 和“允许调用的其他助手”列表，修复底部卡片溢出和窄窗口布局问题。
- 界面语言与对话时区并排显示，在较小屏幕上自动回落为纵向布局。
- 每次回答完成后显示总用时；模型等待、搜索与长任务继续显示动态状态，降低“卡死”的误解。
- G-LLM 官方接口 `https://llm.gprophet.com/v1` 中，以 `:free` 结尾的模型显示免费样式，其余模型显示付费样式。第三方与自部署接口不套用该规则。

## 图片生成编排

- 明确区分“看图”和“生图”：视觉模型可以理解图片，但不会因此被当作图片生成模型。
- 聪明的聊天模型可以先理解需求并整理完整生图提示词，再调用同一供应商中真正标记为生图能力的模型。
- 工作区不再使用当前聊天模型错误请求 `/images/generations`；没有可用生图模型时也不会向助手暴露生图工具。
- 生图结果会显示实际使用的模型，方便排查上游模型能力和路由配置。

## 更新方式

- Windows V2.0.13 用户可由客户端自动下载并安装 V2.0.14。
- Apple Silicon Mac（M1/M2/M3/M4 等）：下载 `G-LLM-Client-Setup-2.0.14-arm64.dmg`。
- Intel Mac：下载 `G-LLM-Client-Setup-2.0.14-x64.dmg`。
- Linux：可选择 `x86_64.AppImage` 或 `amd64.deb`。
- 本版本继续采用无证书发布；Windows/macOS 可能显示未知发布者或安全警告，macOS 与 Linux 仍需手动更新。

## English Summary

V2.0.14 advances assistants into reusable business-execution units. Assistants can create and update goal-based plans, use shared workspace and extension tools, and delegate bounded tasks only to explicitly authorized assistants. Skills can be created or uploaded as Markdown, evaluated, versioned, iterated from feedback, and rolled back.

The release improves the Extension Tool Center, delegated-assistant lists, personalization layout, narrow-window overflow, and elapsed-time feedback. On the official G-LLM endpoint only, `:free` models receive a Free badge and other models receive a Paid badge.

Image generation now separates prompt authorship from rendering. A capable chat model may understand the request and produce a complete prompt, while the client routes the actual `/images/generations` call to an image-capable model from the same provider. Vision input is not treated as image generation, unavailable tools are hidden, and completed output identifies the model used.

Windows V2.0.13 clients can install this release through the in-app updater. macOS and Linux remain manual downloads under the current certificate-free distribution model.
