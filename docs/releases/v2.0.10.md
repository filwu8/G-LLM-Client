# G-LLM Client V2.0.10

V2.0.10 集中修复模型上游故障、工作区文件交付、诊断能力和 Markdown 显示问题，让客户端在模型能力或兼容网关表现不稳定时给出更可靠、可理解的结果。

## 模型请求与错误提示

- 工作区模型请求遇到临时网络错误、限流或可恢复的上游故障时会自动重试，并在界面中显示重试进度。
- 修复部分推理模型只返回推理过程、没有最终答复时被错误视为成功的问题；用户会收到明确提示并可切换模型重试。
- 文件任务中模型没有调用实际写入工具时，客户端不再声称任务完成，而是尝试引导模型执行所需操作。
- 统一识别上游繁忙、超时和路由错误，向用户提供“切换其他模型后重新发送”的简明建议，同时把技术细节保留在本地诊断中。

## Word、PDF 与最终交付物

- 新增原生 PDF 生成工具，既可直接把 Markdown 标题、列表和表格渲染为 PDF，也可将已有 Word 文档转换为 PDF。
- 增加最终产物契约校验：用户明确要求 Word 或 PDF 时必须交付对应格式，并检查指定文件名、禁止格式和单一最终文件要求。
- Word 表格继续使用真正可编辑的原生表格；生成完成后会验证 DOCX 正文和表格结构，PDF 则验证文件签名和非空内容。
- 文档补充样式或 Logo 时默认更新同一个交付文件，除非用户明确要求保留多个版本。

## 诊断与恢复

- 普通聊天和工作区任务会在本机保存结构化运行时间线，包括模型请求、重试、工具、授权、产物验证、Token 和最终状态。
- 应用重启后，未完成的旧任务会标记为“已中断”，避免界面或诊断记录长期停留在虚假运行状态。
- 设置页新增“一键导出诊断报告”，导出的 JSON 会对凭据做脱敏，并包含最近运行记录和主日志尾部，便于远程排查用户机器上的失败原因。

## Markdown 显示

- 修复 `**结论：**如果……` 这类粗体结束符紧接中文或英文正文时直接显示星号的问题。
- 新的显示规范化会按分隔符顺序处理同段多个粗体片段，并跳过代码块、行内代码、转义和未闭合标记，避免误解析正常内容。
- 修复只作用于显示层，不修改本地保存或复制出来的模型原始 Markdown。

## 更新方式

- Windows V2.0.9 用户可由客户端自动下载并安装 V2.0.10。
- Apple Silicon Mac（M1/M2/M3/M4 等）：下载 `G-LLM-Client-Setup-2.0.10-arm64.dmg`。
- Intel Mac：下载 `G-LLM-Client-Setup-2.0.10-x64.dmg`。
- Linux：可选择 `x86_64.AppImage` 或 `amd64.deb`。
- 本版本继续采用无证书发布；Windows/macOS 可能显示未知发布者或安全警告，macOS 与 Linux 仍需手动更新。

## English Summary

V2.0.10 improves model-request resilience, workspace artifact delivery, diagnostics, and Markdown rendering. Temporary network and upstream failures are retried with visible progress, while reasoning-only or tool-free file responses are no longer reported as successful. Busy and routing failures now show concise guidance to switch models instead of exposing opaque gateway payloads.

The workspace agent adds native PDF generation and validates the user's requested Word/PDF format, filename, single-final-file constraint, and editable Word tables. Generated DOCX and PDF files receive structural verification before delivery.

Regular chat and workspace tasks now persist a local structured run timeline with retries, tools, approvals, artifact verification, token usage, and terminal states. Settings can export a credential-redacted JSON diagnostic report, and unfinished runs are marked interrupted after an app restart.

Markdown display now repairs bold delimiters that touch following Chinese or English text while preserving multiple bold spans, fenced code, inline code, escaped markers, stored messages, and copied source Markdown.

Windows V2.0.9 clients can install this release through the in-app updater. macOS and Linux remain manual downloads under the current certificate-free distribution model.
