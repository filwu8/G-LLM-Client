# G-LLM Client 2.0.34 Windows update

Application version `2.0.34`, Windows x64 MSIX `2.0.34.0`. Store identity, publisher, application ID, `gllm` protocol and storage paths are unchanged.

**简体中文**

- MCP 服务真正接入工作区 Agent。工具中心里配置的 MCP 服务（本地 Stdio、Streamable HTTP、SSE）现在会被实际调用：每轮运行前重新拉取工具清单，连不上时退回上次缓存的清单并写明原因，模型看到的是「连不上」，而不是凭空编造工具。本地 Stdio 进程运行在工作区沙箱之外，因此按外部未隔离操作处理——任何权限模式下都要求逐次确认，「总是允许」不适用。超时和 JSON-RPC 错误不会重试（服务端可能已经执行），只有连接确实断开时才重连一次。
- 新增 Anthropic Messages 与 Google Gemini 原生协议，可以直接对接 Claude 与 Gemini 的官方端点，不必再经过 OpenAI 兼容层。联网检索规划、项目记忆、目标判断、会话排序这些内部调用也按同一协议发送，此前它们固定发送 OpenAI 请求体，对原生端点必然 404。知识库改为关键词与向量的混合检索：有 embedding 模型时启用向量召回，没有时退回关键词，设置中新增「自动检索知识库」开关，默认开启。
- 任务不再以「未完成」收尾。缺少信息、进度停滞、同一工具反复失败、验收不通过、后台任务挂起或达到轮数上限时，Agent 会暂停并提问，而不是输出一个失败结果。回答会回填给同一个任务继续执行；每次任务最多问三次，同一个问题不会重复问。模型请求最终失败（额度耗尽、上游故障）也走这条路——那是用户可以决定的事：换模型或重试。明确拒绝审批仍按用户的决定停下。
- 重试提示合并成一行。此前一次上游故障会打印几十行「自动重试模型请求」，而且不说明在等谁。现在合并为一条「模型重试中（第 N 次）· 域名 · 秒数」，文字带流光动效，点击可以展开目标服务、累计次数、最近原因和开始时间。普通聊天的等待倒计时也会标出请求的域名。
- 修复超长内容撑坏聊天面板。一条消息里的长 JSON 曾把面板撑到 5000 多像素宽，模型选择器和发送按钮被推出窗口并裁掉，看起来就像「模型按钮消失了」。现在超长代码在代码块内部横向滚动，工具栏保持单行，模型名过长时截断；付费与免费模型改用颜色区分，不再用汉字挤占位置。
- 删除项目会一并清理它的会话、笔记、记忆、工具、技能、助手和助手排序。此前只删项目这一行，关联数据永久留在磁盘上，而且每次保存都被重写一遍。
- 修复打包版 About 面板把「启动时刻」当成构建码。`app.asar` 内的文件时间由 Electron 用当前时钟伪造，旧的取值方式因此总是显示启动那一分钟。改为打包时注入真实构建码；拿不到可信值时只显示版本号，不再编一个数字。
- 依赖与发布流程。修掉两个 moderate 级依赖公告（MCP TypeScript 客户端、fflate）；第三方声明补回 632 个此前漏收的生产依赖；构建不再依赖 `pnpm licenses list`（它在干净环境中必然失败），CI 门禁改为直接校验声明文件。

**English**

- MCP servers now actually reach the workspace agent. Servers configured in the tool centre (local Stdio, Streamable HTTP, SSE) are called for real: the tool list is fetched before every run, a failed fetch falls back to the last cached list and states why, so the model sees "cannot connect" instead of inventing tools. A local Stdio process runs outside the workspace sandbox and is therefore treated as an external unconfined operation — every call needs its own confirmation in any permission mode, and "Always allow" is never offered. Timeouts and JSON-RPC errors are not retried, because the server may already have executed them; only a connection that is actually gone is retried once.
- Native Anthropic Messages and Google Gemini protocols. Claude and Gemini endpoints can be used directly instead of through an OpenAI-compatible shim. Internal calls — search planning, project memory, goal judging, conversation ordering — use the same protocol; they used to send an OpenAI body and could only 404 against a native endpoint. The knowledge base now retrieves with keywords and vectors together: vector recall when an embedding model is available, keyword search when it is not, with a new "automatically search the knowledge base" setting that is on by default.
- A run no longer ends with "task incomplete". When information is missing, progress stalls, the same tool keeps failing, acceptance fails, a background job hangs or the turn ceiling is reached, the agent pauses and asks instead of printing a failed result. The answer is fed back into the same run; at most three questions per run, and the same question is never asked twice. A model request that finally fails — quota exhausted, upstream outage — takes the same route, because switching models or retrying is the user's decision. An explicit approval denial still stops the run, as the user asked.
- Retry feedback is one line. An outage used to print dozens of "automatically retrying the model request" rows with no indication of whom it was waiting for. It is now a single "retrying the model (attempt N) · host · seconds" line with a light sweep, and clicking it reveals the target service, total attempts, latest reason and when the wait started. The plain-chat countdown names the host it is calling as well.
- Fixed very long content breaking the chat panel. Long JSON in one message could stretch the panel past 5000 pixels, pushing the model picker and send button out of the window where they were clipped — it looked as if the model button had disappeared. Long code now scrolls inside its own block, the toolbar stays on one row and long model names are truncated. Paid and free models are distinguished by colour instead of taking up space with extra characters.
- Deleting a project now removes its conversations, notes, memories, tools, skills, assistants and assistant ordering too. Previously only the project row was removed, so the related records stayed on disk forever and were rewritten on every save.
- Fixed the packaged About panel treating the launch moment as a build code. File times inside `app.asar` are fabricated by Electron from the current clock, so the old lookup always showed the minute the app started. The code is now injected when the bundle is built, and when no trustworthy value exists the label shows the version alone rather than inventing a number.
- Dependencies and release tooling. Two moderate advisories are fixed (the MCP TypeScript client and fflate); the third-party notice file gains 632 production dependencies it had been missing; the build no longer depends on `pnpm licenses list`, which cannot work in a clean environment, and the CI gate validates the notice file directly.
