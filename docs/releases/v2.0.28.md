This version is not publicly released or submitted for Store certification. Public release metadata in the root READMEs is intentionally unchanged. Windows MSIX version: `2.0.28.0`, x64. Existing package identity, protocol, Store-managed updates and platform signing/sandbox settings are retained; uncommitted Mac work is not assumed present or copied.

## 功能与边界

首次使用通过 `https://llm.gprophet.com/client/connect` 注册或登录。网页登录态负责创建一次性授权码，客户端复用现有 `gllm://providers/api-keys` 解析与固定 HTTPS 兑换接口，在主进程兑换个人凭据并加密保存，刷新真实模型列表后选择可用对话模型。等待、取消、超时、重复回调及网络失败均有处理。模型列表刷新失败时保留已经安全保存的凭据，重试不再次兑换已消费的授权码。

额度由主进程使用已保存的官方供应商凭据请求固定 `/api/client/account`，禁止重定向和自定义地址。界面显示 `remaining_quota / quota_per_unit` 计费单位，不把额度解释为模型 token，不写死赠送数量。零余额、令牌撤销及服务不可用提供提示；查询失败不删除密钥、不阻断聊天。没有新增充值、购买或客户端发放额度逻辑。

供应商凭据使用 Electron safeStorage 的系统加密后端保存，并验证加解密结果。密钥存储不可用或密文无法解密时保留原记录，提示解锁或重新连接，不明文回退。旧版明文配置在安全后端可用时升级；历史备份不会被自动改写。加密配置跨设备复制后可能需要重新连接。加密保护磁盘存储，不替代操作系统账号安全。

No real credentials or paid model calls are used in these probes. HTTP 200 from SPA fallback alone was not treated as deployment evidence. A real user's authorized handoff, usable model list and valid-token allowance response must still be verified before a full online end-to-end claim or Store submission. Anonymous 401 verifies authentication routing, not successful account access.
