# G-LLM Client V2.0.6

V2.0.6 是首个启用 Windows 客户端内自动更新的桥接版本，同时修复 NVIDIA Nemotron 推理模型无内容显示及切换模型状态不同步的问题。

## Windows 自动更新

- Windows 客户端启动 30 秒后检查更新，之后每 12 小时检查一次。发现新版本后会自动在后台下载，下载完成后可立即重启安装，也可在正常退出时安装。
- 稳定版拒绝预发布版本和版本降级，更新文件按发布元数据中的摘要校验。
- 正式发布继续生成 SHA-256 清单和 GitHub artifact attestation，并只上传白名单内的三平台安装包与更新元数据。
- 本版本延续此前的无证书发布方式，Windows 可能显示未知发布者或安全警告；取得 Authenticode 证书后将补充操作系统级发布者验证。
- macOS 无签名应用不符合 Electron 自动更新要求，因此本版本继续检查新版本并引导用户手动下载；Linux 同样保持手动更新。

> V2.0.5 及更早版本未启用自动安装，因此仍需从官网下载并手动安装 V2.0.6 一次。安装 V2.0.6 后，后续 Windows 版本即可在客户端内自动更新。

## NVIDIA Nemotron 推理模型兼容

- 支持 OpenAI-compatible 流式响应中的 `reasoning_content`、`reasoning` 和嵌套推理字段。
- 修复使用 `nvidia/nemotron-3-nano-omni-30b-a3b-reasoning` 时界面长期停留在“正在等待响应”但不显示推理或答案的问题。
- 忽略仅包含空白、角色或结束标记的流式分片，并兼容非 SSE JSON 响应，避免错误结束或漏掉最终内容。
- 推理过程与最终答案分别显示；没有独立答案时也会保留模型实际返回的推理内容。

## 模型切换与会话状态

- 暂停当前回复后切换模型，会话模型、输入框右下角模型和“本会话已切换”提示保持一致。
- 后台会话完成或失败时不再用旧快照覆盖当前会话刚选择的模型。
- 快速对话与主窗口共享相同的模型切换和流式状态保护。

## 下载选择

- Windows：选择 `G-LLM-Client-Setup-2.0.6-x64.exe`。
- Apple Silicon Mac（M1/M2/M3/M4 等）：选择 `G-LLM-Client-Setup-2.0.6-arm64.dmg`。
- Intel Mac：选择 `G-LLM-Client-Setup-2.0.6-x64.dmg`。
- Linux：可选择 `x86_64.AppImage` 或 `amd64.deb`。

## English Summary

V2.0.6 is the first bridge release with in-app automatic updates on Windows. The Windows client checks after launch and every 12 hours, downloads updates in the background, and installs them on restart or normal app exit. Release assets retain SHA-256 manifests, GitHub artifact attestations, one-time version targeting, and updater metadata checks.

This release continues the existing certificate-free distribution model, so Windows and macOS may show unknown-publisher or security warnings. Users of V2.0.5 and earlier must manually install V2.0.6 once; later Windows releases can update inside the client. macOS remains a manual download because Electron requires a signed macOS application for automatic installation. Linux also remains manual.

This release also supports OpenAI-compatible reasoning streams that use `reasoning_content` or related fields, fixing the indefinite waiting state with `nvidia/nemotron-3-nano-omni-30b-a3b-reasoning`. It additionally keeps the selected model consistent after stopping a response, switching models, or receiving background conversation updates.
