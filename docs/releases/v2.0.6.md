# G-LLM Client V2.0.6

V2.0.6 是首个启用安全自动更新的签名桥接版本，同时修复 NVIDIA Nemotron 推理模型无内容显示及切换模型状态不同步的问题。

## 安全自动更新

- Windows 正式安装包强制使用 GPROPHET LIMITED Authenticode 签名和受信任时间戳。
- macOS 正式安装包强制使用 Developer ID Application 签名、hardened runtime 和 Apple notarization，并验证 stapled ticket 与 Gatekeeper。
- 正式发布工作流使用受保护的 `production-release` 环境；缺少任一签名凭据或任何验证失败时，不会创建 GitHub Release。
- 客户端启动 30 秒后检查更新，之后每 12 小时检查一次。发现新版本后会自动在后台下载，下载完成后可立即重启安装，也可在正常退出时安装。
- 稳定版拒绝预发布版本和降级，Windows 会验证更新安装包发布者，macOS 依赖 Developer ID、Gatekeeper 与 notarization 信任链。

> V2.0.5 及更早版本未启用自动安装，因此仍需从官网下载并手动安装 V2.0.6 一次。安装 V2.0.6 后，后续已签名版本即可在客户端内自动更新。

## NVIDIA Nemotron 推理模型兼容

- 支持 OpenAI-compatible 流式响应中的 `reasoning_content`、`reasoning` 和嵌套推理字段。
- 修复使用 `nvidia/nemotron-3-nano-omni-30b-a3b-reasoning` 时界面长期停留在“正在等待响应”但不显示推理或答案的问题。
- 忽略仅包含空白、角色或结束标记的流式分片，并兼容非 SSE JSON 响应，避免错误结束或漏掉最终内容。
- 推理过程与最终答案分别显示；没有独立答案时也会保留模型实际返回的推理内容。

## 模型切换与会话状态

- 暂停当前回复后切换模型，会话模型、输入框右下角模型和“本会话已切换”提示保持一致。
- 后台会话完成或失败时不再用旧快照覆盖当前会话刚选择的模型。
- 快速对话与主窗口共享相同的模型切换和流式状态保护。

## 下载选择

- Windows：选择 `G-LLM-Client-Setup-2.0.6-x64.exe`。
- Apple Silicon Mac（M1/M2/M3/M4 等）：选择 `G-LLM-Client-Setup-2.0.6-arm64.dmg`。
- Intel Mac：选择 `G-LLM-Client-Setup-2.0.6-x64.dmg`。
- Linux：可选择 `x86_64.AppImage` 或 `amd64.deb`。

## English Summary

V2.0.6 is the first signed bridge release with secure automatic updates. Production Windows packages require a GPROPHET LIMITED Authenticode signature and trusted timestamp. Production macOS packages require Developer ID signing, hardened runtime, Apple notarization, a stapled ticket, and Gatekeeper verification. The release workflow fails closed when any credential or verification is missing.

Users of V2.0.5 and earlier must manually install V2.0.6 once. After that, signed Windows and macOS releases are checked automatically, downloaded in the background, and installed on restart or normal app exit.

This release also supports OpenAI-compatible reasoning streams that use `reasoning_content` or related fields, fixing the indefinite waiting state with `nvidia/nemotron-3-nano-omni-30b-a3b-reasoning`. It additionally keeps the selected model consistent after stopping a response, switching models, or receiving background conversation updates.
