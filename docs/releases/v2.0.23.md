# G-LLM Client V2.0.23

V2.0.23 adds conversational installation of Markdown skills while retaining the existing spaces, assistants, and conversations.

## 在对话中安装助手技能

- 在主窗口或快速会话上传 `.md` / `.markdown` 文档，然后发送“给当前助手安装我上传的 Skill”。也支持 HTTPS 文档链接、GitHub 文件页面、Markdown 代码块与当前空间已有技能的准确名称。
- 默认绑定到当前助手，也可指定当前空间中已有助手的名称。用户通过切换助手选择技能组合；安装规则不需要模型 API Key 或文件夹授权。
- 同一助手可以绑定多个技能。重复安装相同名称和规则会复用已有记录；通过对话安装最多启用 20 个技能，达到上限会提示调整绑定。
- 技能、助手绑定和成功消息一起保存，安装结果同步到主窗口与快速会话。取消操作、来源不完整、下载失败或内容超限均提供可操作的说明。
- 新增“会议纪要整理”示例，可在助手设置中管理技能绑定。
- 更新 `fast-uri` 与 `undici` 的补丁版本，修复发布依赖审计发现的高危公告。

## 当前支持范围

本版安装的是 Markdown 规则文档：单份文档不超过 1 MB，规则不超过 50,000 字符。整个目录、ZIP、附带脚本、依赖和资源暂不随规则安装；文档引用附带资源时会明确提示。多个已启用技能的规则一起加载，用户最新明确要求优先。技能之间的自动冲突处理和按任务选择技能尚未实现。

## 平台与升级

提供 Windows x64、macOS Intel / Apple Silicon、Linux x64 安装包。Windows 保留客户端内更新；macOS 和 Linux 使用手动下载更新。当前安装包沿用无商业代码签名证书的发布方式，Windows 可能显示未知发布者提示，macOS 可能显示 Gatekeeper 提示。升级保留原有对话和配置。

## English Summary

V2.0.23 lets users install Markdown skills through the main window or Quick Chat. Upload a document and ask to install it for the current assistant, provide an HTTPS Markdown link or GitHub file page, include a Markdown code block, or name an existing skill in the current space. Installation binds to the current assistant by default or to an explicitly named existing assistant. A model API key and folder authorization are not required.

Users select their capability combination by switching assistants. Matching names and rules reuse existing records, and conversation installation allows up to 20 enabled skills. The skill, binding, and successful chat receipt are saved together and synchronized between windows. Cancellation, download problems, incomplete documents, and size limits have actionable messages.

The `fast-uri` and `undici` transitive dependencies are updated to patched versions to address high-severity advisories reported by the release dependency audit.

This release imports Markdown rules only, with a 1 MB document limit and a 50,000-character rule limit. Directories, ZIP archives, scripts, dependencies, and resources are not installed. Referenced resources are called out in the receipt. Bound enabled rules load together; automatic skill selection and conflict resolution are not included.

Packages are provided for Windows x64, macOS Intel and Apple Silicon, and Linux x64. Windows supports in-app updates; macOS and Linux use manual downloads. Packages continue without commercial platform-signing certificates, so Windows may show an unknown-publisher warning and macOS may show a Gatekeeper prompt. Existing conversations and settings are retained on upgrade.
