# G-LLM Client V2.0.11

V2.0.11 集中修复快速对话开始响应时的排版、Windows 滚动条可见性，以及从快速对话切换到主窗口后打开错误会话的问题。

## 快速对话排版

- 修复等待模型响应时状态文案被旧动画选择器错误设置为 `7px × 7px`，导致中文逐字竖排并溢出气泡的问题。
- 流式显示会临时补齐尚未闭合的粗体、删除线和行内代码标记，减少模型刚开始输出时 Markdown 结构反复变化造成的跳行。
- 快速对话正文统一使用主窗口的 Markdown 布局规则；显示层修复不会改写、保存或复制合成标记。

## Windows 滚动体验

- Windows 快速对话始终启用纵向滚动模式，并为滚动条预留稳定空间。
- 加宽滚动条并提升滑块和轨道对比度，深色与金色主题下都能清楚识别和拖动。
- 保留鼠标滚轮、触控板和“回到最新消息”的原有行为。

## 会话上下文交接

- 点击快速对话的“打开主窗口”前会保存当前会话，避免最新流式内容尚未落盘。
- 交接请求同时携带空间、助手和会话 ID，主窗口不再沿用之前选中的会话或按最近更新时间猜测。
- 主窗口仍在启动时，交接请求会由预加载层暂存，界面就绪后再准确选择目标会话。
- 如果目标会话属于其他空间，主窗口会先切换到对应空间，再恢复同一助手、会话和完整上下文。

## 更新方式

- Windows V2.0.10 用户可由客户端自动下载并安装 V2.0.11。
- Apple Silicon Mac（M1/M2/M3/M4 等）：下载 `G-LLM-Client-Setup-2.0.11-arm64.dmg`。
- Intel Mac：下载 `G-LLM-Client-Setup-2.0.11-x64.dmg`。
- Linux：可选择 `x86_64.AppImage` 或 `amd64.deb`。
- 本版本继续采用无证书发布；Windows/macOS 可能显示未知发布者或安全警告，macOS 与 Linux 仍需手动更新。

## English Summary

V2.0.11 fixes Quick Chat layout instability, Windows scrollbar visibility, and exact conversation handoff to the main window.

The waiting card no longer applies its dot-animation dimensions to status text, and streaming Markdown temporarily closes unfinished bold, strikethrough, and inline-code markers for stable narrow-window layout without changing stored or copied content. Quick Chat also shares the main window's Markdown content structure.

Windows Quick Chat now reserves a visible 12-pixel vertical scrollbar with improved dark- and gold-theme contrast while preserving wheel, touchpad, and jump-to-latest behavior.

Opening the main window now saves the live Quick Chat conversation and sends its exact space, assistant, and conversation IDs. The request is buffered during startup, and the main UI switches space when necessary before selecting the same conversation and context.

Windows V2.0.10 clients can install this release through the in-app updater. macOS and Linux remain manual downloads under the current certificate-free distribution model.
