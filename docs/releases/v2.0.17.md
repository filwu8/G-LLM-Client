# G-LLM Client V2.0.17

V2.0.17 让自主目标更懂上下文、联网研究更可控，并解决 Windows 大小窗口切换时容易误判状态或丢失草稿的问题。

## 更聪明的自主目标

- 打开目标模式时，输入框中尚未发送的内容会自动成为“最终目标”初稿，用户只需补充验收标准和执行边界。
- 新增智能延续、完整上下文、仅相关历史和独立目标四种上下文策略。默认的智能模式会判断新目标与此前任务是否相关：相关时承接必要上下文，无关时隔离旧对话干扰。
- 无论采用哪种上下文策略，助手仍能在用户明确授权的工作文件夹内观察和交付真实成果。

## 更可控的联网研究

- 联网策略可按目标单独设置为自动、开启或关闭，不再只能依赖会话级偏好。
- 来源范围支持全网、优先疑似官网，以及严格限定用户指定的域名。
- “疑似官网”会结合站点特征与多个搜索引擎的交叉结果判断，并明确标注为未经认证；用户指定的域名也会按“用户指定”展示，不会被包装成官方来源。
- 工作区任务会使用用户时区下的真实当前日期和时间，减少报告年份错误、过期信息误判和错误生成时间。

## 不丢输入的窗口体验

- Windows 主窗口最小化后，点击桌面宠物或托盘图标会恢复主窗口，而不是误开快速对话。
- 主窗口关闭后再点击入口会打开快速对话；快速对话自身隐藏后也会恢复快速对话，行为更符合用户预期。
- 主窗口与快速对话共享当前会话、授权工作区和未发送草稿，在大小窗口之间切换不再丢失输入内容。
- Windows 托盘图标恢复为此前经过实际验证的样式，macOS 菜单栏与 Dock 行为保持不变。

## 更广泛的项目入口

- GitHub README 新增繁体中文、日语、韩语、西班牙语、葡萄牙语、德语、法语、俄语、阿拉伯语、印地语和印度尼西亚语入口，连同简体中文和英文共覆盖 13 种语言。
- 各语言页面统一呈现核心价值、主要能力、下载入口、许可证和安全说明，帮助更多地区的用户快速判断产品是否适合自己。

## 安全与质量

- 升级生产环境 URI 解析依赖，清除发布门禁中的全部高危依赖告警。
- 新增目标上下文、目标搜索范围和窗口恢复路径的自动测试，降低后续优化造成体验回退的风险。

## 更新方式

- Windows V2.0.16 用户可由客户端自动下载并安装 V2.0.17。
- Apple Silicon Mac（M1/M2/M3/M4 等）：下载 `G-LLM-Client-Setup-2.0.17-arm64.dmg`。
- Intel Mac：下载 `G-LLM-Client-Setup-2.0.17-x64.dmg`。
- Linux：可选择 `x86_64.AppImage` 或 `amd64.deb`。
- 本版本继续采用无证书发布；Windows/macOS 可能显示未知发布者或安全警告，macOS 与 Linux 仍需手动更新。

## English Summary

G-LLM Client V2.0.17 makes autonomous goals more context-aware, web research more controllable, and conversations more resilient across window changes. Opening Goal mode now carries the unsent composer text into the objective. Users can choose Smart, Full context, Relevant history, or Isolated goal behavior, so related tasks continue naturally while unrelated work avoids stale context.

Each goal can independently control web access and choose between the open web, likely official sources, or an exact domain allowlist. Likely-official results are explicitly marked as unverified, while user-provided domains are labeled as user-specified rather than certified. Workspace runs also receive the real current date and time in the configured timezone, reducing stale report years and incorrect freshness judgments.

On Windows, minimizing the main window and clicking the mascot or tray icon restores that same window; closing the main window opens Quick Chat on the next click, and hiding Quick Chat reopens Quick Chat. Drafts, conversation identity, and workspace authorization survive transitions between both window sizes. The GitHub project now offers 13 language entry points so more users can quickly understand the product, its capabilities, and download options. The production URI parser is also upgraded to clear all high-severity dependency findings from the release gate.
