# G-LLM Client V2.0.4

这次更新的重点，是让联网搜索真正帮助你理解和解决问题，而不只是罗列几个看似相关的网页。

## 你会感受到的变化

### 联网研究更可靠、更贴近真实用途

- 同时使用 Google、Bing 和 DuckDuckGo 搜集候选资料；对于时效性问题，还会补充 Google News。
- 如果 Google 在当前网络被防火墙、验证码、JavaScript 验证或同意页阻断，客户端会自动切换到其他可用引擎，不再把“无法访问 Google”误判为“网上没有答案”。
- 搜索前会先理解你的目标，围绕用途、能力、限制、风险、替代方案和验证路径组织查询，而不是简单重复你的原话。
- 自动识别重复、过时、缺少上下文或不适用于当前场景的内容，并保留不同来源之间的重要冲突，方便模型给出多种视角。
- 新增证据审计，可查看本次实际使用和不可用的搜索引擎、采纳与排除的来源，以及证据覆盖情况。

### 搜索过程更透明，等待感更低

- 查询标签、搜索状态和来源卡片会随着结果返回逐步出现，不再等所有引擎结束后一次性显示。
- 某个搜索引擎先返回，其结果就会先进入分析；较慢或不可用的引擎不会阻塞其他来源。
- 搜索完成后的模型回答恢复流式输出，可以边生成边阅读。

### 修复金色模式和引用显示

- 修复金色模式下主聊天区域的异常配色。
- 修复 LLM 回复中引用卡片超出聊天区域的问题，长标题、网址和摘要现在能正确收缩与换行。
- 修复内部安全分类标签被误当作模型正文显示的异常情况。

### 安全与稳定性

- 升级 Electron 及相关运行时依赖，消除发布检查发现的全部高危依赖漏洞。
- 新增 32 项自动化测试，覆盖联网研究策略、搜索结果解析、证据治理、异常回复过滤及既有核心功能。

## 使用提示

- 已有聊天记录不会自动重新搜索；请在新消息中重新提问，以使用新的联网研究流程。
- 可用搜索引擎会因用户所在网络而不同。客户端会自动降级，并在证据审计中说明本次实际可用情况。
- Windows 与 macOS 安装包目前仍未进行平台签名，系统可能显示安全提醒；自动下载安装会在签名和 macOS notarization 配置完成后启用。

## 下载选择

- Windows：选择 `G-LLM-Client-Setup-2.0.4-x64.exe`。
- Apple Silicon Mac（M1/M2/M3/M4 等）：选择 `G-LLM-Client-Setup-2.0.4-arm64.dmg`。
- Intel Mac：选择 `G-LLM-Client-Setup-2.0.4-x64.dmg`。
- Linux：可选择 `x86_64.AppImage` 或 `amd64.deb`。

## English Summary

V2.0.4 introduces intent-aware, progressive web research across Google, Bing, DuckDuckGo, and Google News, with automatic fallback when an engine is blocked. It improves source deduplication, freshness and applicability checks, conflict handling, and evidence auditing. Search progress now appears incrementally and final answers stream again. The release also fixes gold-theme chat colors, overflowing citation cards, abnormal safety labels, and all high-severity dependency advisories detected by the release gate.

Windows and macOS packages remain unsigned during the current transition, so the operating system may display a security warning.
