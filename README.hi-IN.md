G-LLM Client, GPROPHET LIMITED द्वारा विकसित Windows, macOS और Linux के लिए एक डेस्कटॉप AI क्लाइंट है। यह सहायक-केंद्रित ऐप मॉडल कॉन्फ़िगरेशन, ज्ञान संदर्भ, स्क्रीनशॉट प्रश्न, फ़ाइल समझ, बातचीत और कार्यक्षेत्र के कार्यों को एक साथ लाता है।

## मुख्य सुविधाएँ

- भूमिका-आधारित सहायक, जिनके मॉडल, Skills, टूल और सहयोगी सहायक कॉन्फ़िगर किए जा सकते हैं।
- उपयोगकर्ता द्वारा अधिकृत फ़ोल्डर में फ़ाइलें पढ़ना, बदलना और बनाना, साथ ही कार्य की प्रगति दिखाना।
- योजना बनाने, टूल चलाने, लगातार काम करने और परिणाम जाँचने के लिए स्वायत्त लक्ष्य मोड।
- क्लाउड, स्थानीय कंप्यूटर और LAN पर OpenAI-compatible API का समर्थन।
- वेब खोज, चित्र निर्माण मॉडल, ज्ञान आधार, त्वरित चैट और स्थानीय उपयोग आँकड़े।
- बातचीत, सेटिंग और कार्य डेटा डिफ़ॉल्ट रूप से स्थानीय रूप में संग्रहीत होते हैं।
