G-LLM Client est un client d’IA de bureau pour Windows, macOS et Linux, développé par GPROPHET LIMITED. Centré sur les assistants, il regroupe la configuration des modèles, les références de connaissances, les captures d’écran, la compréhension de fichiers, les conversations et les tâches d’espace de travail.

## Fonctionnalités principales

- Assistants spécialisés avec modèles, Skills, outils et assistants collaborateurs configurables.
- Lecture, modification et création de fichiers dans les dossiers autorisés, avec suivi visible des opérations.
- Mode objectif autonome pour planifier, utiliser des outils, travailler en continu et vérifier les livrables.
- Compatibilité avec les API OpenAI-compatible dans le cloud, en local et sur le réseau LAN.
- Recherche web, modèles de génération d’images, base de connaissances, chat rapide et statistiques locales.
- Les conversations, réglages et données de travail sont stockés localement par défaut.

## Installation
